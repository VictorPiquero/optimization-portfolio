# Linear Programming

This section contains introductory mathematical optimization problems focused on learning the fundamentals of **Linear Programming (LP)** and **Mixed-Integer Linear Programming (MILP)**.

The problems are formulated mathematically and solved using different optimization tools, including **Gurobi and Excel Solver**.

## Objectives

- Understand the fundamentals of Linear Programming and Mixed-Integer Linear Programming.
- Formulate optimization problems using decision variables, objective functions, and constraints.
- Learn how to model continuous and binary decisions.
- Implement and solve mathematical optimization models using different tools.
- Analyze and interpret optimization results.

## Problems

| Problem | Type | Tool |
|---|---|---|
| Product Mix | LP | Gurobi |
| Fixed-Charge Problem | MILP | Excel Solver |

## Concepts Covered

- Linear Programming (LP)
- Mixed-Integer Linear Programming (MILP)
- Continuous decision variables
- Binary decision variables
- Resource and capacity constraints
- Fixed and variable costs
- Linking constraints
