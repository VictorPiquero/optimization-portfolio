# Optimization Portfolio

A collection of Operations Research and Optimization projects implemented in Python.

This repository documents my learning journey in mathematical optimization, focusing on logistics, supply chain management, routing, and decision-making problems. The goal is to build a complete portfolio of optimization models using professional optimization tools such as Gurobi, OR-Tools, and Pyomo.

---

## Objectives

- Learn mathematical optimization through practical projects.
- Implement classical Operations Research problems.
- Compare exact optimization methods and heuristic approaches.
- Build a professional portfolio for Optimization Engineering and Supply Chain Analytics.
