# Optimization Portfolio

A collection of **Operations Research and Optimization projects** implemented mainly in Python.

This repository documents my learning journey in mathematical optimization, with a particular focus on **logistics, routing, supply chain management, and decision-making problems**.

The goal is to progressively study different optimization problems, understand their mathematical formulations, and implement them using optimization tools such as **Gurobi** and **lp_solve**, while gradually exploring other frameworks and solution approaches.

## Current Focus: Routing Problems

The current focus of the portfolio is the study of **Vehicle Routing Problems**, following a progressive approach from simpler routing models to more realistic variants:

```text
Traveling Salesman Problem (TSP)
        ↓
Vehicle Routing Problem (VRP)
        ↓
Capacitated Vehicle Routing Problem (CVRP)
        ↓
Capacitated Vehicle Routing Problem with Time Windows (CVRPTW)
```

For these problems, different mathematical formulations and implementations are explored using **lp_solve and Gurobi**.

The objective is not only to obtain optimal solutions, but also to understand how additional real-world constraints affect the mathematical model and computational complexity.
