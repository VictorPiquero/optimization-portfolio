# Datasets

This directory contains the datasets and benchmark instances used throughout the projects.

Datasets may include:

- Transportation problem instances
- Assignment problem instances
- Facility location datasets
- Bin packing datasets
- Traveling Salesman Problem (TSP) instances
- Capacitated Vehicle Routing Problem (CVRP) instances
- Vehicle Routing Problem with Time Windows (VRPTW) instances

Whenever possible, publicly available benchmark datasets will be used.
